# Production prompts

All concepts are high-fidelity 16:9 desktop website mockups for Checkmark Audio. Shared brand constraints: deep black, charcoal, warm cream, champagne gold, restrained signal-red accent, editorial high-contrast serif, expressive italic, condensed uppercase labels, authentic recording-studio photography, no invented claims, no pricing, no fabricated testimonials, no extra team members, no watermark. Shared navigation: `CHECKMARK AUDIO`, `HOME`, `SERVICES`, `STUDIO A`, `STUDIO B`, `TEAM`, `COMMUNITY`, `Q & A`, and `BOOK A FREE CONSULTATION`.

## Studio A / Studio B paired system

Reference template: `03-dark-cinematic-artist-homepage.png`. The four numbered concepts are paired: Studio A and Studio B must look like sibling pages built from the same components, grid, type scale, button language, gold rules, red detail, image treatment, and responsive-friendly section logic.

### Concept 01 — cinematic split-screen room portrait

- Studio A: monumental `STUDIO A` serif title over a high-contrast black-and-white large-room session image; a narrow warm-color equipment/room strip at right; three factual use chips: `BANDS`, `INSTRUMENTS`, `MIX + MASTER`; short line `BUILT FOR THE BIGGER SESSION.`; lower cream information deck with `BEST USES`, `THE ROOMS`, `PLAN YOUR SESSION`.
- Studio B: same structure and proportions with an intimate vocal-booth image; chips `VOCALS`, `DEMOS`, `ACOUSTIC`; short line `FOCUSED ROOM. DIRECT WORKFLOW.`; lower cream information deck with the same headings.

### Concept 02 — noir filmstrip / room sequence

- Studio A: left vertical title rail, three cinematic frames across the hero showing larger room, instrument area, and control-room workflow, numbered `01 02 03`; restrained body copy and consultation CTA.
- Studio B: identical system showing vocal booth, compact instrument room, and close engineer workflow; same numbering and placement.

### Concept 03 — gold architectural room panels

- Studio A: black canvas with warm-gold architectural grid; one dominant room photo, two inset detail photos, oversized outlined `A`, thin acoustic-diagram lines, compact factual labels only.
- Studio B: same system with oversized outlined `B`, intimate room imagery, vocal booth and acoustic-instrument emphasis.

### Concept 04 — immersive room journey / numbered scenes

- Studio A: large edge-to-edge cinematic photograph with a floating black editorial panel, vertical `THE ROOMS`, scene counter, and three large navigable scene tabs.
- Studio B: exact sibling layout using closer, more intimate imagery and distinct scene crops.

## Q & A

### Concept 01 — signal-path question index

An audio-console-inspired editorial layout: monumental `Q & A`, six horizontal signal channels with one question per channel, tiny gold index numbers, one expanded cream answer panel, red active-state light, clear `STILL HAVE A QUESTION?` CTA. Questions: free consultation; first-time artists; file formats; remote mixing and mastering; session preparation; full bands, drums, podcasts, or voice-over.

### Concept 02 — ask-the-engineer editorial desk

Warm cream editorial page with a dark asymmetrical photo of a studio microphone and engineer workspace, oversized serif question mark, stacked question cards like annotated cue sheets, handwritten red circles/arrows used sparingly, black footer CTA.

### Concept 03 — patchbay knowledge grid

Dark modular patchbay grid where each question is a clearly legible large card connected by gold signal lines; selected answer opens as a bright cream module. Functional, playful, easy to translate to CSS Grid and accessible accordions.

### Concept 04 — vinyl liner-notes index

Mostly cream, highly typographic music-publication layout: huge black `QUESTIONS / ANSWERS`, red catalog numbers, two-column index, one large black answer block, circular record-groove motif, gold consultation button.
