# Drafts

Drafts are not the active website. The canonical in-development website is at the repository root.

- `active/` — only work Bridget expects someone to continue. Every off-direction idea gets one descriptively named, dated folder with its own README. Do not place loose competing site files here.
- `reference/` — retained visual studies and protected concepts. They may inform a specifically requested comparison but never override root.

When a draft is rejected or permanently superseded, move it to the appropriate `ARCHIVE/` location. When a draft is merely paused but still useful for comparison, move it to `reference/`. Do not duplicate the same concept between these locations.

Assets inside old references may have stale paths. Repair paths only when Bridget explicitly revives that concept.
