# Image Alt-Text Rules

- Describe what is visible and why it matters in that page context.
- Add service context only when accurate.
- Add location only when natural, useful, and confirmed.
- Do not copy the filename mechanically.
- Never hide keyword lists in alt text.
- Decorative images use empty alt text.
- Linked images describe the link's function when that is more important than appearance.
- Permission, compression, dimensions, caption, credit, and nearby context are separate requirements.
