# Archive

Archived and ignored material lives here.

- `design-drafts/`: old website preview stacks and visual concepts that should not drive the future design by default.
- `ignored-local/` is ignored by Git and can hold HAR exports, temporary raw downloads, and other local-only files.
- `reference/`: old school, imported conversion, imported brand/UI, and legacy DOCX reference material.
- `reference/consolidated-md-sources/2026-07-02/`: granular Markdown files preserved after consolidation into active master planning files.
- `project-system-before-simplification-2026-07-16/`: preserved planning documents and records from the numbered folder system that preceded the six-folder layout. Active media was transferred into `MEDIA/`.
- `old-website-directions/`: superseded root pages and separate team-profile drafts.
- `old-website-directions/root-homepage-before-recovered-main-2026-08-21/`: the homepage replaced when Bridget's recovered design became canonical.
- `old-website-directions/mockup-before-root-build-2026-08-11/`: the former top-level mockup, retained only as history.
- `design-drafts/website-design-drafts/recovered-preview-before-promotion-2026-08-21/`: pre-promotion copies and handoff material from the recovered preview.
- Do not use archived material as the active website source of truth unless Bridget deliberately promotes it into `START_HERE/`, `MEDIA/`, `DRAFTS/`, `EMAIL/`, or the root website.
