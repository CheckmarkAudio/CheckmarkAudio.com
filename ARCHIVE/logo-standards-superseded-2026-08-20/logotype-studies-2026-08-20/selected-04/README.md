# Selected Direction 04 — White Hairline Lockup

This folder contains the selected experimental-minimal direction 04 with its color corrected to match the official white transparent logo.

## Locked specifications

- Isotype source: `MEDIA/IMAGES/checkmark-audio-logo-official-white-transparent.png`
- Isotype modification: none; it is only proportionally scaled and positioned
- Wordmark: `CHECKMARK AUDIO`
- Typeface: Optima Regular
- Wordmark color: `#FFFFFF` (RGB 255, 255, 255)
- Hairline color: `#FFFFFF` (RGB 255, 255, 255)
- Background: transparent in the production exports

## Files

- `checkmark-audio-selected-04-white-transparent-2400.png` — full-resolution transparent PNG
- `checkmark-audio-selected-04-white-transparent-1200.png` — smaller transparent PNG for website testing
- `checkmark-audio-selected-04-white-transparent.svg` — scalable layout containing the unchanged official PNG isotype
- `checkmark-audio-selected-04-white-on-black-preview.png` — review preview only

The source isotype supplied for this selection is a PNG, so the composite SVG retains that raster isotype rather than claiming to be a fully vectorized logo.

## True outlined vector

The later true-vector export converts every visible element to paths and shapes:

- `checkmark-audio-selected-04-white-true-vector.svg` — complete transparent vector lockup
- `checkmark-audio-isotype-white-traced-vector.svg` — vector isotype by itself
- `checkmark-audio-optima-wordmark-white-outlined.svg` — outlined wordmark by itself
- `checkmark-audio-selected-04-white-true-vector-2400.png` — transparent PNG rendered from the true vector
- `checkmark-audio-selected-04-true-vector-preview.png` — black-background review preview

The isotype vector was traced directly from the approved 2000×2000 official PNG and measured at 99.79% binary silhouette overlap. The Optima lettering is stored as outlined glyph paths. The complete SVG therefore has no live text, font dependency, mask, or embedded raster image.

Optima is a licensed system typeface already installed on the Mac used for this work. The font itself is not repackaged or redistributed; outlining the approved wordmark makes the logo portable without requiring recipients to install Optima.
